# Evidence-Ledger Pilot Intake Templates

Complete these templates using **sanitized, authorized-to-share** data only. Preserve all header names exactly. Do not add a sheet, a formula, passwords, or source-system credentials. The full package and validation rules are defined in `../single-customer-pilot-playbook.md`.

The intake is a **dry-run package** until an authorized Earthward workspace user reviews the validation report and explicitly applies it. A label in `ledger_events.csv` is provenance only; it does not create a user account or approval authority.

`access_roster.csv` contains user email addresses and must travel through the agreed secure channel. It should not be placed in a general email attachment or shared-drive link.
